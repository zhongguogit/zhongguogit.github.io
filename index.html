联审官 · 招募中

招募联审官（志愿者 · 无报酬）

本庭实行多人联审制：每案至少两名联审官到庭方可开庭，联审官未到，案件候审。
联审官为纯志愿者，没有任何报酬——庭里只给一样东西：排名与荣耀。凭认同「先审后跑」的理念入庭，凭良心落笔。

结案 = 亲手联审落笔的案件数 · 锦旗 = 受助者回帖所送（个人锦旗计入被感谢者，团队锦旗到庭联审官各记一面） · 解惑 = 回帖答疑帮助的人数
全庭功德：结案 0 · 锦旗 0 · 解惑 0 —— 每一件都终身留档于起居注，头衔出勤十案进一阶

三条铁律

先审后跑
命令先过目，看懂了才执行，不审不动。
先备份后修改
改任何东西之前，关键文件先留备份。
出事可回滚
任何操作都要有退路，坏了能恢复。
