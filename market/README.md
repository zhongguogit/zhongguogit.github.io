# 市场 · 运营手册（给站长）

## 一句话说清这门生意

> **别人卖提示词，我们收 3%。**

卖家不用建站、不用接支付、不用找客户；买家不用在十几个群里翻聊天记录。
平台做两件事：**把货摆整齐** + **把钱收上来分对账**。

---

## 一、三步上线（约 3 分钟）

### 1. 建表

Supabase → SQL Editor → 粘 `market/schema.sql` → Run。

### 2. 上传文件

把 `market/` 整个目录和更新后的 `pay/` 推到仓库根目录即可。

### 3. 验收

打开 `https://zhongguogit.github.io/market/`，应该看到分类条 + 空列表 + 「没有商品」提示。
点「我要上架」，填完提交，会拿到一个 `MK...` 编号 —— 说明写库通了。

---

## 二、审核流程（每天 10 分钟）

新提交的商品 `status = 'review'`，默认**不显示**在市场里。审核动作只有一句 SQL：

```sql
-- 通过
update public.market_items set status='live' where item_id='MK2610173821';

-- 打回（附理由，通过念白告诉卖家）
update public.market_items set status='offline' where item_id='MK2610173821';

-- 看今天待审的
select item_id, title, price, seller, created_at
from public.market_items where status='review' order by created_at;
```

**审核只看四件事：**

| 检查项 | 不通过的样子 |
|---|---|
| 免费层能不能真跑通 | 贴一段「请输入你的小说，AI 会帮你」——这不算提示词 |
| 付费层写得实不实 | 「更多惊喜」「详情私聊」 |
| 有没有卖别人的东西 | 整段抄了别人的付费课程 |
| 有没有违规承诺 | 「保证过稿」「包月入过万」 |

前两项最重要。**免费层跑不通的商品，退款率会吃掉你所有利润。**

## 三、买家下单之后，钱怎么走

现在的实现（收款码 + 人工核验）是这样的：

```
买家在 /market/ 点商品
  → 跳 /pay/?type=market&item=MK...&price=39
  → 扫码付给【站长】
  → 填联系方式提交，订单进 orders 表
  → 站长在 /admin/ 看到订单 → 手动标记已开通
  → 同时把这条成交录进 market_orders（算 3%）
  → 通知卖家发货（微信）
```

**为什么钱先进站长？** 因为只有一个收款码。
如果让每个卖家自己收款，平台就抽不到 3%——只能靠自觉，那不叫生意。

**所以结算规则必须写死：**

| 项目 | 规则 |
|---|---|
| 抽成基数 | 实际成交额（`gross`） |
| 比例 | 3% |
| 买家付 | 标价，不额外加价 |
| 卖家得 | `gross × 97%` |
| 结算周期 | 每月 1 号 |
| 起结额 | ¥50，未满顺延 |
| 退款单 | 不计入抽成，已抽的退回 |

录入成交的一条 SQL（或做成后台按钮）：

```sql
insert into public.market_orders
  (order_id, item_id, item_title, seller, gross, fee_pct, fee_amount, net_to_seller, buyer_contact, status)
values
  ('ZG2610173821', 'MK2610173821', '豆包 · 小说改短剧分镜', '卖家微信',
   39, 3, 1.17, 37.83, '买家微信', 'delivered');
```

月末看谁该拿多少：

```sql
select * from public.seller_payout order by payout_total desc;
```

## 四、这件事的天花板（先说清楚）

**能做到的：**

- 零成本上线，不交保证金、不注册公司
- 3% 抽成在同类里偏低（知识付费平台常见 10–30%），这是唯一能打的差异点
- 商品按「豆包 / 扣子 / 千问」分类，比「提示词大全」更好搜

**做不到的，别骗自己：**

| 做不到 | 为什么 | 要花多少才能做到 |
|---|---|---|
| 自动分账给卖家 | 个人码没有分账 API | 企业主体 + 微信支付服务商资质 |
| 自动发货 | 静态站没有服务端 | 云函数 + 商品文件存对象存储 |
| 防刷单 | anon key 公开，谁都能插数据 | Supabase Auth + 严格 RLS |
| 卖上万单 | 人工核验是瓶颈 | 上面三条全做了才行 |

**所以现实路径是：** 先月销 20–50 单，验证「确实有人愿意付」；到这个量级再考虑上企业主体做自动化。
在那之前，任何自动化投入都是浪费。

## 五、怎么让第一批人上架

空市场没人来，没人来就更空。破局只有一条：**你自己先上 10 个**。

具体做法：

1. 用 `content.md` 里的 12 个种子商品，先上 6 个真能用的
2. 每个都标 `seller: 'zhongguogit'`，价格定低（9.9–19）
3. 有 3 笔真实成交、有 2 条真实评价之后，再去拉人
4. 拉人时不要讲「平台抽 3%」，要讲「**我这儿已经有买家了，你上架就有单**」

第 4 条是全部关键。抽成比例从来不是卖点，**流量才是**。
