# 照抄单 · 8 个示例（含合规红线）

> 方法：只拆三样——**卖什么 / 怎么让人看见 / 怎么收钱**。
> 拆第四样（他的供应链、他的私域、他的投放）就容易崩，也容易越界。

## 示例 1：小区代买菜（实物+服务）

```
📋 照抄单 · 对象：本小区做了半年的李姐
  他卖什么：每天早市代买，跑腿费 5 元/次 + 菜钱实报
  他怎么让人看见：业主群每天发一张"今日菜价 + 实拍图"
  他怎么收钱：微信转账，先收菜钱再买
  → 我们照做：1. 建一个自己的群 2. 每天发一张实拍 3. 固定 5 元跑腿费
  → 必须改的：用自己拍的图，别搬李姐的
  ⚠ 实物食品注意：只代买不加工，不承诺"绝对新鲜"，避免纠纷
```

## 示例 2：图文排版小活（纯服务）

```
📋 照抄单 · 对象：闲鱼上做公众号排版的卖家
  他卖什么：一篇公众号排版 50–120 元
  他怎么让人看见：商品标题写"公众号排版 当天交 可改3次"
  他怎么收钱：闲鱼拍下，交付后确认收货
  → 我们照做：1. 同样句式挂闲鱼 2. 用免费编辑器 3. 承诺 24 小时交
  → 必须改的：描述里写清"不含文案撰写"
  ⚠ 不要承接医疗、金融、教育培训类文案排版，涉及资质
```

## 示例 3：手机贴膜/换电池（手艺）

```
📋 照抄单 · 对象：地铁口摆摊的小哥
  他卖什么：贴膜 15 元，换电池 80 元（含电池）
  他怎么让人看见：摆一块手写价目牌 + 当场演示贴膜
  他怎么收钱：当面扫码
  → 我们照做：1. 写价目牌 2. 先给熟人免费贴 3 次练手 3. 再摆出来
  → 必须改的：自己练熟再收费，贴坏要赔
  ⚠ 换电池涉及拆机风险，先只做贴膜
```

## 示例 4：二手书回收转卖（实物）

```
📋 照抄单 · 对象：多抓鱼模式（个人版）
  他卖什么：低价收旧书，整理后加价卖
  他怎么让人看见：拍"书况实拍 + 一句话推荐"
  他怎么收钱：平台挂售，卖出后结算
  → 我们照做：1. 先收 10 本熟人旧书 2. 拍书况 3. 挂二手平台
  → 必须改的：自己拍实拍图，标注品相（全新/九成新/有笔记）
  ⚠ 盗版书绝对不收；教材类注意版本
```

## 示例 5：宠物上门喂养（服务）

```
📋 照抄单 · 对象：本地宠物群里的兼职
  他卖什么：上门喂猫 30 元/次，含添粮换水铲屎
  他怎么让人看见：群内发"服务流程 + 实拍视频"
  他怎么收钱：先付定金，服务完付尾款
  → 我们照做：1. 写清服务清单 2. 拍一段自己喂猫的视频 3. 固定 30 元
  → 必须改的：必须签一份简单免责说明（宠物伤人/生病）
  ⚠ 不接病宠、不接烈性犬；进门全程录像
```

## 示例 6：Excel 表格代做（技能）

```
📋 照抄单 · 对象：淘宝上的表格代做店
  他卖什么：简单表格 30 元，带公式 80 元
  他怎么让人看见：主图写"不会做表格？发需求当天出"
  他怎么收钱：拍下付全款，改 2 次
  → 我们照做：1. 挂同样句式 2. 先做 3 个免费样例当作品 3. 定 2 档价
  → 必须改的：写清"不含数据录入"
  ⚠ 不接含个人隐私数据的表格，接了要签保密
```

## 示例 7：短视频剪口播（技能）

```
📋 照抄单 · 对象：剪映模板作者
  他卖什么：一条口播剪辑 60–150 元
  他怎么让人看见：发"前后对比"短视频
  他怎么收钱：先付 50%，交付付尾款
  → 我们照做：1. 剪 3 条自己的当作品 2. 发对比视频 3. 定价按条
  → 必须改的：素材版权要客户提供并授权
  ⚠ 不接需要"搬运"他人视频的单
```

## 示例 8：手工饰品（实物）

```
📋 照抄单 · 对象：小红书上做串珠的博主
  他卖什么：手工手串 39–69 元
  他怎么让人看见：拍制作过程 + 上手效果
  他怎么收钱：小红书店铺或私信转账
  → 我们照做：1. 先做 5 条 2. 拍制作过程 3. 定价 39 起
  → 必须改的：全部自己拍、自己做
  ⚠ 用真实材质标注，不用"水晶能量"等功效宣称
```

## 通用合规红线（照抄前必看）

| 品类 | 红线 |
|---|---|
| 食品 | 需食品经营许可；自制食品不能随便卖 |
| 医疗/保健 | 禁止宣称疗效；器械需注册证 |
| 教育/培训 | 学科类培训受限；不得承诺提分 |
| 金融/理财 | 无牌照不得提供投资建议 |
| 化妆品 | 需备案；不得宣称"美白祛斑"等特殊功效 |
| 二手奢侈品 | 假货风险极高，务必验真 |

**遇到以上品类，第一步就说"这个需要证，先别碰"，然后换方向。**
