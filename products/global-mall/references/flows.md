# 全流程示意图与单证清单

## 一、九步流程一图看懂

```
[R 入口] 每方派风险承担责任人才登记 → 取得 RB 凭证
    ↓
[预约缴费] 凭 RB 进入 → 交付平台费用 → 取得 GM 凭证
    ↓
[E0 核验] RB×5 + GM 凭证 → 齐全才解锁流程
    ↓
[海外买家 B]──需求──▶[G0 商品确认]◀──报价──[中国商品方 S]
                          │
                     [G1 合规初筛]◀──执行──[管理服务方 A]
                          │
        [G2 报价+物流方案]◀──运力──[物流方 L]──清关协助──[海外中转仓 T]
                          │
                     [G3 资金通道确认]
                          │
                [G4 备货]→[G5 出口报关]→[G6 国际运输]
                          │
              [G7 目的国清关+尾程派送]→[G8 签收+费用全额退回]
```

## 二、每步的单证/动作清单

| 闸门 | 谁动手 | 必须产生的单证/记录 |
|---|---|---|
| G0 | B+S | 商品确认单（双语品名、HS 前 6 位、数量、单价、交期、退货档位） | 
| R 入口 | 各方 | 责任凭证 RB-____（每方一位真实的人，逐字承诺 + 签署）——没人担责不得进入预约 |
| 预约缴费 | 各方 | 订单凭证 GM-____（凭 RB 才能进入；款项进平台前无服务入口） |
| E0 | 各方 | RB×5 + GM 核验记录——两证齐全流程才解锁 |
| C 担保 | C 委员会 | 高货值/首单/带电等订单须有 C 委员作 C-RB 担保（经严苛落地考察+保证金+当地法律程序确认），否则停在 E0 |
| G1 | A | 合规初筛表（类别 + 证件清单 + 绿黄红灯结论） |
| G2 | S+L+T | 分段报价单（货款/国内段/国际段/关税预估/中转操作费）+ 监管方式判定 |
| G3 | 各方+平台 | 支付凭证号登记表 + 平台费用交付与"全流程后退回"规则确认书 |
| G4 | S | 出库三照（外观/铭牌/包装）+ 与确认单比对记录 |
| G5 | L | 报关单号 / 清单号；三单一致性核对记录 |
| G6 | L | 运单号 + 轨迹链接 |
| G7 | T | 目的国税费告知书（当日口径）+ 买家书面确认；清关放行单 |
| G8 | B+A | 签收确认；平台费用全额退回记录；订单关闭单 |

## 三、会员与费用机制（平台规则，skill 只记录不碰钱）

1. **预约制**：任何一方先申请加入平台 → 资质审核 → 配对成团 → 开订单。
2. **使用前交费（准入条件）**：五方各自向平台交付当期平台服务费（金额由平台公示）。
   **款项未进入平台之前，skill 不开启任何服务入口**——E0 会员核验是硬闸门，见 SKILL.md 第二节。
3. **风险责任人（R 入口）**：每方必须派一位「风险承担责任人才」走进 R 入口登记（真实姓名+联系方式+逐字责任承诺），取得 RB 责任凭证后方可进入预约缴费；卡点报告须由责任人本人签字，skill 不对外承担任何风险。
4. **全流程后退回**：订单走完 G8（签收无争议）后，平台将各方交付的费用**全额退回**。
   - 设计意图：让各方零成本试用、放心使用；平台实际收入来自后续增值服务（而非这笔押金式费用）。
   - skill 的职责：在 G3 登记"已交付"，在 G8 触发"应退回"，超时跟催。
   - **注意**：这是平台运营承诺，不是 skill 的能力。skill 无法强制平台退钱，用户应保留凭证。
4. **货款路径**：B → 合规跨境支付通道 → S，skill 仅登记凭证号；争议时作为对账依据。

## 五、与"传统电商"的对照（为什么说是"绕过电商"的一次尝试）

| | 传统大平台 | 本 skill 模式 |
|---|---|---|
| 找货 | 平台内搜索 | 需求确认单直连卖家 |
| 定价 | 平台定价/活动 | 分段报价（货、运、税分开） |
| 物流 | 平台统一 | 按商品特性选渠道，单证透明 |
| 退货 | 平台规则兜底 | 下单前书面约定三档退货路径 |
| 争议 | 平台仲裁 | 卡点报告 + 五方风险共认 |
| 合规 | 平台背书 | 各方自持资质，skill 把关流程 |

诚实结论：**"绕过电商"绕过的是"信息与定价中介"，绕不过"申报与支付合规"。** 本 skill 的价值就是把后者做成一张人人能看懂的清单。
