# 政策背景（为什么这条路现在走得通 / 哪里还不通）

> 本文件所有条目给出公告号或官方来源，便于核对。政策会变，执行前以海关/税务当日口径为准。

## 1. 海关监管方式：五条通道怎么选

| 代码 | 全称 | 适用场景 | 关键特征 |
|---|---|---|---|
| **9610** | 跨境贸易电子商务（直邮出口） | 境内电商/个人经平台卖给**境外个人消费者**，小包直邮 | 「清单核放、汇总申报」；综试区内单票 ≤5000 元且不涉证涉税的 B2C 商品可「清单核放、汇总统计」简化通关。链路短、时效快，最适合厨具、日用品等轻小件直邮 |
| **9710** | 跨境电商 B2B 直接出口 | 境内企业经跨境电商平台卖给**境外企业** | 无货值上限；2025 年起部分关区要求电子合同经认可平台签订 |
| **9810** | 跨境电商出口海外仓 | 先批量备货到海外仓，售出后从仓发 | 「单未下、货先行」；2025 年第 3 号公告：离境即退税、销售再核算 |
| **1210** | 保税跨境贸易电子商务 | 货物以保税状态进出海关特殊监管区域 | 进出口均适用；区内理货拼箱后申报离境即可退税 |
| **1039** | 市场采购贸易 | 经认定的市场集聚区（如义乌）采购，小商户拼单出口 | 单票 ≤15 万美元；免征增值税、申报简化。**注意**：有经营者误将大额订单套用 1039 被补税处罚的案例 |

来源：海关总署公告 2014 年第 12 号（9610）、2014 年第 57 号（1210）、2020 年第 75 号（9710/9810）；各综试区解读。

**给老外的一句话版本**：买一两件寄到家 = 9610 直邮；替公司/商店采购一批 = 9710；常住想反复买 = 看平台是否有海外仓 9810。

## 2. 「三单对碰」：为什么订单、支付、物流必须一致

9610 通关要求电商企业、支付企业、物流企业分别向海关传输订单、支付单、物流单，海关比对放行。
**推论**：本 skill 在 G5 闸门要求三单齐备且信息一致——品名、数量、金额对不上就过不去。
这也是"绕过电商"的边界所在：**可以不用大平台下单，但必须有一个合规的交易与申报载体**（自建站、市场采购平台或外贸综合服务企业代申报）。

## 3. 检疫与证件对照表（初筛用，G1 闸门）

| 商品类别 | 中国出口侧 | 目的国进口侧（常见，须逐国核对） |
|---|---|---|
| 不锈钢厨具、陶瓷餐具 | 无特殊许可证；食品接触材料建议提供符合 GB 4806 的检测报告 | 欧盟需符合食品接触材料 (EC)1935/2004；美国 FDA 食品接触材料要求 |
| 牙刷、牙线 | 普货，无证 | 多数国家普货；欧盟需 CE 无关（非器械），注意标签语言 |
| 电动牙刷、剃须刀（含锂电池） | 锂电池航空运输 UN38.3 + 空运鉴运报告 | 部分承运人拒收散件锂电池；IATA 规则限制 |
| 带插头小家电 | 3C 认证（中国强制，出厂需有） | 欧盟 CE/LVD；英国 UKCA；美 UL（非强制但渠道要求）；插头制式转换 |
| 化妆品、牙膏（含氟） | 出境无特殊证，但成分申报要真实 | 各国准入差异极大：东盟/海湾有注册制，欧盟需 CPNP 通报——**多数情况个人直邮会被卡，提前告知** |
| 食品、保健品、药品 | 出口需相应许可 | 几乎所有国家均需进口许可——**本 skill 默认建议不做** |
| 木制品、竹制品 | 熏蒸/热处理（IPPC 标识） | 普遍要求，缺 IPPP 印章会被扣 |
| 动植物源（羽毛、骨、壳） | 濒危/检疫审查 | 严格限制——默认拒绝 |

**结论口诀**：厨具餐具日用品 = 绿灯可做；带电 = 黄灯找专门渠道；吃的东西和药 = 红灯不做。

## 4. 退运政策：退货为什么"现在"比以前容易

- 海关总署 2023 年公告：跨境电子商务出口**退运商品**免征进口关税和进口环节增值税、消费税（限 9610/9710/9810/1210 出口且 1 年内退运，在综试区内）。
- 这解决了"退回中国要再交一次税"的老问题——退货三档方案里的第 3 档（退回中国卖家）因此可行。
- 注意：免的是税，不免税款之外的**往返运费**，运费谁担必须在 G0 就写清。

## 5. 目的国侧的老外须知（写进 G7，逐国更新）

- **美国**：个人进口免税额度（de minimis）2025 年经历重大调整，小包免税红利收窄，直邮前必须查当日口径。
- **欧盟**：所有进口包裹（无论货值）均需 IOSS/VAT 申报，关税免征额各国不同（多为 €150 以下免关税但仍需 VAT）。
- **英国**：£135 以下 VAT 由卖家代扣。
- **东盟/中东**：多实行注册制与 SASO/G-Mark 等符合性认证，个人直邮常被退回。

**skill 的做法**：G7 闸门强制 T（中转仓）向 B 出示目的国当日口径，B 书面确认后才派送。

## 6. "深化改革后最先进的方法"归纳（本 skill 采信的五个抓手）

1. **综试区便利包**：清单核放、汇总统计；无票免税；企业所得税核定征收（应税所得率 4%）。
2. **9810 离境即退税**：货先出去，销售再核算——备货海外仓的资金压力大幅下降。
3. **出口退运免税**：让"退货地址在中国"从绝路变成可走通的路。
4. **三单电子化**：订单/支付/物流自动对碰，个人小单也能阳光清关——这是"点对点直购不靠大平台"的制度基础。
5. **市场采购 1039**：让没有进出口权的小商户也能合法把货卖出去（但有额度与范围约束）。

> ⚠ 以上第 1–3 点依赖商品从**综试区/认定市场**出口。skill 在 G1 会问一句：卖家所在城市是否在跨境电商综试区名单内——不在的话，便利政策打折扣，如实告知。
