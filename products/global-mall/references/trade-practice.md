# 国际贸易实务实操参考（trade-practice.md）

> 供「全球购物中心」skill 在 G1–G8 各闸门调用。所有口径以申报当时有效的
> 官方政策为准；本文件不构成法律/报关意见。

## 一、Incoterms 2020 速查（个人跨境直购场景）

| 术语 | 风险分界 | 出口报关谁办 | 国际运费谁出 | 保险谁买 | 本 skill 推荐度 |
|---|---|---|---|---|---|
| EXW | 卖家工厂门口 | 买家 | 买家 | 买家 | ★（老外几乎用不了） |
| FCA | 交给买家指定承运人 | 买家 | 买家 | 买家 | ★★ |
| FOB | 装运港船上 | 卖家 | 买家 | 买家 | ★★★★★ 首选 |
| CIF | 装运港船上 | 卖家 | 卖家 | 卖家（最低险别） | ★★★ |
| CIP | 交给第一承运人 | 卖家 | 卖家 | 卖家（ICC(A)） | ★★★ |
| DAP | 目的地交货 | 卖家 | 卖家 | 买家 | ★★ |
| DDP | 买家门前完税 | 卖家 | 卖家 | 卖家 | ★★（需 T 方有清关资质） |

要点：术语 = 风险分界线 + 费用分界线。报价单必须写「术语 + 具体交货点」，
例如 `FOB Ningbo`，不能只写 FOB。

## 三、付款节点模板（平台池内 + T/T 双轨）

```
池内（默认）：买家全款入池 → G4 备货核验放 30% → G6 出运放 40% →
G8 签收放 25% → 退运期满放 5%（会员费全流程后全额退回）

池外备选（T/T）：签单付 30% 定金 → 发货前付清 70%
禁止：100% 赊销陌生买家 / 100% 预付陌生卖家 / 私人账户收款
```

## 四、运输保险速查（G6 必答）

- 条款：海运按 CIC（人保）或 ICC(A)；空运按 Air Clause(A)；
- 保额 = 发票金额 × 110%（行业惯例，含 10% 期望利润）；
- 高频拒赔原因：包装不当（易碎品未打木架）、险别选低（只保 ICC(C)）；
- 不投保订单：风险分界点之后灭失由买家自担，G2 必须明示 + 买家签字 + RB 复签。

## 六、争议与不可抗力条款模板（G2 报价附件）

```
不可抗力：因疫情、口岸关闭、战争、极端天气导致之延误，双方互不追责；
责任方须在 72 小时内向平台报备卡点（卡点编号 + 证据）。
争议路径：B↔S 协商 48h → T/A 调解 72h → C 委员裁决 → 平台按责处置会员费。
```

## 七、每单最低单证四件套

1. 商业发票 Commercial Invoice（品名/HS/数量/单价/贸易术语）
2. 装箱单 Packing List（毛净重、箱规、件数）
3. 运单 AWB / B-L（与发票品名严格一致，错一个词清关就卡）
4. 原产地证 CO / FORM E / RCEP 证书（按目的国优惠协定选，省关税的关键）

医械/食品/化妆品另加：出口销售证明、自由销售证书、目的国注册证——
证件不全不发货（G4 卡点）。
