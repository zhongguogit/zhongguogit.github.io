# 记忆回溯 · memory-recall

> 你不需要记住"我把东西存在哪了"。
> 你只需要记得**一个词**——人名、项目名、金额、日期、甚至当时说的一句话。
> 剩下的交给我：我把跟这个词有关的一切翻出来，按时间排好，告诉你来龙去脉。

---

## 〇、先看这一屏：不用再到处找 skill 了

> **有事就问它。它会的直接做，它不会的告诉你去哪，绝不让你更迷茫。**

### 0.1 为什么不再需要"找 skill"

找 skill 本身就消耗心力：你不知道该找哪个、找到的也不一定合适、装多了又记不住哪个干什么。

所以这个 skill 的定位是**总入口**：

```
你随便说一句（哪怕说得很乱）
        ↓
它先判断：这件事属于哪一类
        ↓
┌───────────────┬──────────────────┬─────────────────┐
│  它会做        │  它会一半         │  它不会          │
│  （占大多数）  │  （有现成套路）   │  （明确说不会）   │
├───────────────┼──────────────────┼─────────────────┤
│ 直接给你结果   │ 给顺序 + 照念稿   │ 告诉你去哪 + 一句话怎么问 │
└───────────────┴──────────────────┴─────────────────┘
```

**关键**：三种情况**都不会让你空手走**。最差也是一种情况——它会说"这个我不行，但你去 XX，问的时候这么说"。

### 0.2 它自己能干什么（不用再找别的）

| 你说什么 | 它直接做 |
|---|---|
| "我忘了那个 XX 的事" | 一个特征词翻出全部相关记忆 + 时间线 + 当前卡点 |
| "这个我不会 / 从哪下手" | 弹同类案例 + 三句照念稿，照着念就能往下走 |
| "这句话怎么说才好" | 给照念稿（≤25 字，念完对方必接话） |
| "这事的顺序是什么" | 给固定顺序（检测→备案→上架 这类） |
| "已经搞砸了怎么办" | 给补救顺序（越早越好） |
| "帮我把关于 XX 的都删了" | 预览 → 确认 → 删 → 24 小时内可撤回 |
| "备份一下 / 换手机了" | 快照 / 纯特征导出 / 合并恢复 |
| "我以前是怎么做的" | 从历史里翻出你当时的原话 |

**这八类覆盖了日常绝大多数"卡住"**。剩下的，交给下面这张表。

### 0.3 它不会的，去哪儿（一次说清，别再来回找）

| 你真正要的 | 该找谁 | 一句话怎么问 |
|---|---|---|
| 写长文/公文/论文 | 文档类 skill（docx / 写作） | "帮我写一份 XX，800 字，面向 XX" |
| 做 PPT | 演示类 skill | "做 10 页，讲 XX，给 XX 看" |
| 处理 Excel / 算账 | 表格类 skill | "把这个表按 XX 汇总，出个图" |
| 做图 / 改图 | 绘图类 skill | "生成一张 XX 的图，风格 XX" |
| 做视频 | 视频类 skill | "用这几段素材，剪个 60 秒的" |
| 查最新资讯 / 价格 | 联网搜索 | "查一下 XX 现在多少钱，要最近的" |
| 写代码 / 改 bug | 编程类 skill | "这段报错，帮我看看哪里的问题" |
| 医疗 / 法律 / 税务的专业判断 | **人**（医生/律师/税务师） | — |

> ⚠️ 最后一行很重要：**它不会假装自己能做医疗、法律、税务的专业判断**。
> 它能帮你**整理材料、列问题清单、说明一般规则**，但**不能替代持证专业人士**。
> 这一条不因为是"小事"就松口——误诊、误判的代价是你承担。

### 0.4 一句保底话术（拿不准时就这么说）

不用想"这该归哪类"，直接说：

```
「我遇到个事：______。你看着办，会做就做，不会就告诉我该找谁。」
```

它一定会给你三种之一：**直接做 / 给顺序 / 指路**。**不会让你带着问题离开。**

### 0.5 唯一的例外

下面这些，它**不做也不指路**，只拒绝并说明原因：

- 伪造材料（报告/资质/产地/授权）
- 骗人话术（虚假宣传、冒充、绕过平台）
- 颠倒法律顺序（先上架后补报告、先发货后收钱）
- 医疗/法律/税务的**具体结论**（可以帮你理材料，不能替你下判断）

> 拒绝也是一种"不让你迷茫"——总比给你一条错路好。

## 一、它解决什么（四句话）

1. **不用复制粘贴**。以前你靠"复制到备忘录"，越存越乱，最后不知道哪份是新的；
2. **说一个特征就能找回**。哪怕你忘了文件名、忘了哪天说的，只要记得一个特征词；
3. **能删干净**。说"把关于 XX 的全删了"，连摘要、标签、附件索引一起清，不留半份废物；
4. **还能当加速器**。做事卡住时，它把以前做过的同类事变成"案例"弹出来，你**照着念一句话**就能往下走，不用先学会。

> 第 4 条是它跟"备忘录"最大的区别：备忘录帮你**记住过去**，这个 skill 帮你**跳过现在不会的那一步**。

## 一之二、加速器：弹案例 + 照念一句（核心新能力）

### 1.2.1 它为什么"快"

自己做一件事慢，通常慢在三个地方，都不是"手慢"：

| 慢在哪 | 表现 | 加速器怎么绕 |
|---|---|---|
| **不知道从哪下手** | 打开文档发呆，刷半小时手机 | 直接给你**第一步的一句话**，不给你整套流程 |
| **不懂那个概念** | "什么叫 FOB""什么叫验收标准" | 不解释概念，给你**别人当时怎么说的原话** |
| **怕做错** | 反复改，改到不敢发 | 给你**一个已经成的版本**，你在上面改两个字 |

**所以加速器不教知识，只给"能照着说的那一句"。** 认知不足、知识不够，都能绕过——因为你要的不是懂，是**把这件事做完**。

### 1.2.2 案例从哪来（不用编）

案例**只有一个来源：你自己记录过的历史**。

```
你半年前记过："跟老周谈代发，佣金8个点，最后谈到6个点，条件是月销3000件"
      ↓
今天你在谈另一个供应商，卡在"佣金怎么开口"
      ↓
加速器弹出这条旧案例 → 你照着说："月销3000件的话，能不能到6个点？"
```

**绝不凭空生成案例**。找不到同类历史时，明说"这个我没做过，只能给你一个通用句式"——并且标出来。

### 1.2.3 弹出时机（不停跳，但不烦）

用户要"不停地跳出来"，但也说过"啰嗦但有用"。取中间：**只在四个时刻弹**。

| 时刻 | 触发信号 | 弹什么 |
|---|---|---|
| **① 卡住时** | 用户说"这个我不会/不知道怎么写/从哪下手" | 一条最像的历史案例 + 一句照念稿 |
| **② 要动笔前** | 要写报价/回复客户/发朋友圈/填表 | 一份"上次这么写成的"模板句 |
| **③ 拖了很久** | 同一条记忆 3 天没推进 | 一句提醒 + 一个最小动作（不超过 2 分钟） |
| **④ 刚做完** | 用户说"搞定了/发出去了" | 立刻存为新案例（下次加速用） |

**不弹的时刻**：用户在专注做事、没问、没卡——**不打断**。这是加速器和骚扰的分界线。

### 1.2.4 弹出的固定格式（三行，不超过三行）

```
⚡ 这事你做过（2026-04-12 · M-20260412-003）
   当时是这么说的：「月销3000件的话，能不能到6个点？」
   你现在照着念 → 把"3000"换成你的数，把"6个点"换成你想谈的
```

**规则**：
- 第一行说**什么时候做过**（给人底气："我不是不会，我是忘了"）；
- 第二行给**原话**（不是道理，是能直接念的字）；
- 第三行说**改哪几个字**（只改 1–2 处，改多了又变成"要学"）。

### 1.2.5 语音照念（关键：一句话就够）

用户说的场景是"根据案例提示语音就可以"。所以每条照念稿必须满足：

1. **一口气念得完**（≤ 25 字）；
2. **不用理解也能念**（没有术语，或者术语保留原样不解释）；
3. **念完对方能接话**（是一个问句，或一个明确表态，不是一个陈述）。

✅ 好：「月销3000件的话，能不能到6个点？」（问句，对方必须回答）
✅ 好：「这批我先要300件试销，卖得动再加。」
❌ 差：「关于佣金比例，我希望在考虑量的基础上进行阶梯式议价。」（念完对方不知道怎么接）

### 1.2.6 一次全部搞定（不做"分几步走"）

用户明确要"一次全部搞定"，所以输出**不分阶段**，直接给**完整的一串**：

```
⚡ 你以前这么干过（M-20260412-003）

   照这个顺序念，一次说完：

   ① 先问量：「你们最小起订多少？」
   ② 再压价：「月销3000件的话，能不能到6个点？」
   ③ 留后路：「那我先要300件试销，卖得动再加。」

   ⬆️ 卡在哪句就说"第2句怎么说"，我给你换个说法
```

**为什么这样快**：不用先学谈判、不用先懂行规，**照着念三句就完成一轮**。这就是"绕过认知障碍"的具体样子。

### 1.2.7 案例库怎么长起来（越用越快）

```
第一次做：给你通用句式（标"通用"，不算你的案例）
     ↓ 做完
你说"搞定了" → 自动存成 M-xxx，打 `案例` 标签
     ↓ 下次同类
直接给你**你自己那次的原话**（比通用句式准得多）
```

**所以这个 skill 越用越快**：第 10 次做同类事的时候，它给的已经是你自己的成熟版本，不是通用模板。

### 1.2.8 命令

```bash
# 卡住了，弹案例 + 照念稿
python booster.py "佣金怎么开口"
python booster.py "客户一直拖着不给钱" --script    # --script 输出连读语音稿

# 念完搞定了，存成你自己的案例
python booster.py --save "月销3000件的话，能不能到6个点？" --scene 谈价

# 看全部 60 条通用句式
python booster.py --list
```

### 1.2.8.1 七条分流（每次先判断属于哪一条，顺序不能乱）

```
① 违法需求？        → ⛔ 拒绝 + 给合规替代        （最高优先，先拦）
② 要把顺序倒过来？  → ⚠️ 顺序警告 + 最佳方案（唯一可行）
③ 问「该怎么办」？  → 📋 最佳方案（唯一可行）+ 五步顺序
④ 已经踩错了？      → 🔧 最佳补救方案（唯一可行）
⑤ 它不做的活？      → 🧭 指路：找谁 + 一句话怎么问
⑥ 正常卡住？        → ⚡ 弹案例 + 照念稿
⑦ 什么都不对？      → 🟡 老实说没有，给两个可选动作
```

**为什么先拦①②，再给⑥**：因为加速器一旦先给了话术，用户就会照着做，等发现违法/顺序错了，已经晚了。**先安全，后加速。**
**为什么⑤放在⑥前面**：能指路就指路，别用商务话术去糊一个"做 PPT"的需求。

实测各路径：

| 输入 | 走哪条 | 输出首行 |
|---|---|---|
| "怎么伪造检测报告" | ① | ⛔ 这条我不能给你话术 |
| "能不能先上架后面补报告" | ② | ⚠️ 这一步顺序不能倒 |
| "借条怎么写" / "账号被封了怎么办" | ③ | 📋 最佳方案（目前唯一可行） |
| "已经上架了但没检测报告" | ④ | 🔧 最佳补救方案（目前唯一可行） |
| "帮我做个 PPT" / "我是不是得了胃病" | ⑤ | 🧭 我知道该找谁 |
| "佣金怎么开口" | ⑥ | ⚡ 弹案例 + 三句照念稿 |
| "孩子上学怎么办" | ⑦ | 🟡 老实说没有，不硬编 |

### 1.2.9 加速器的边界（不许吹）

- **只加速"做过的事"**。没做过的，只能给通用句式，且必须标明"这个我没做过"；
- **不替代判断**。照念稿是"能开口"，不是"谈得成"——对方压价你还是要自己决定让不让；
- **不给违规话术**。一句话里出现「伪造／假的／进口／假装／绕过平台／私下交易／治病／不敢投诉／先付款再发货／骗」等词，**直接拒绝**，并给一条合规替代。这类需求一律不给话术：

| 需求 | 为什么拒绝 | 给什么替代 |
|---|---|---|
| "怎么说才显得是进口的" | 虚假产地 | 如实标注产地，用工艺讲差异 |
| "怎么写能让客户以为有检测报告" | 伪造文书 | 缺的报告去补做 |
| "怎么绕过平台私下交易" | 违反规则，买家无保障 | 平台内走流程，用赠品让利 |
| "怎么让他不敢投诉" | 威胁他人 | 把问题解决在前面 |
| "怎么让他相信这个能治" | 违法广告 | 只描述产品本身用途 |

- **不为了"快"省略该走的流程**。合同还是要看，样品还是要验——加速的是"说话"，不是"跳过风险"。

## 一之三、法律与安全：顺序不能颠倒（硬规则）

> 加速器最大的风险不是"给错话术"，是**让人为了快，把该先做的事挪到后面**。
> 这一节是**不可协商**的顺序表。用户要求"倒过来做"，一律拒绝并说明。

### 1.3.1 为什么顺序不能倒

颠倒顺序通常不是"违规"，而是**让前面所有努力归零**：

| 倒了顺序 | 后果 |
|---|---|
| 先上架，后补检测报告 | 平台下架 + 罚款 + 店铺扣分，前期销量全丢 |
| 先收款，后签合同 | 出纠纷时没有约定依据，钱要不回来 |
| 先发货，后收定金 | 货在对方手上，尾款基本收不回 |
| 先宣传"能治"，后想改 | 已经发布的广告构成违法事实，删了也追责 |
| 先私下转账，后想开发票 | 无票无凭证，税务和售后都说不清 |
| 先解封账号，后找证据 | 没有申诉材料，解封概率极低 |

**一句话**：顺序错了，不是"慢一点"，是"重新来一遍，还要赔"。

### 1.3.2 九条固定顺序（每条都只有这一条路）

> 下面每一条的「最佳方案」，就是**目前唯一可行**的做法。
> 不是"其中之一"，是**没有第二种能走通的路**。这一点必须讲明，否则人会去找歪招。

#### ① 卖货：检测 → 备案 → 上架

```
✅ 正确：拿样品 → 送检 → 拿到合格报告 →（需备案的）备案 → 上架 → 开卖
❌ 禁止：先上架卖 → 卖爆了 → 再补报告（平台抽查就是下架 + 罚款）
```
**✅ 最佳方案（目前唯一可行）**：找有 CMA/CNAS 资质的第三方送检 → 同批次留样让报告覆盖整批 → 报告到手再上架，把报告编号填进详情页。
**为什么唯一**：平台资质审核只认**已出具**的合格报告，没有报告连审核都过不了，没有替代入口。
**依据**：《产品质量法》要求产品检验合格方可销售；《电子商务法》要求平台内经营者提交真实资质。

#### ② 收钱：合同 → 定金 → 生产 → 尾款 → 发货

```
✅ 正确：谈定 → 书面确认（微信文字也算）→ 收定金 → 排产 → 收尾款 → 发货
❌ 禁止：先发货 → 再要钱（货在对方手上，你没有任何筹码）
```
**✅ 最佳方案（目前唯一可行）**：微信文字确认规格/数量/金额（对方回复即算）→ 收 30% 定金 → 排产 → 尾款到账当天发货 → 大额走平台担保或对公转账。
**为什么唯一**：货一旦离手，你唯一的筹码就没了；只有"钱在前、货在后"能在不动用诉讼的情况下保障回款。
**依据**：《民法典》合同编——没有约定，举证责任在你。

#### ③ 广告：能证明 → 才敢说

```
✅ 正确：有检测报告 → 说"检测合格"；有专利 → 说"专利号 XXX"
❌ 禁止：先说"全网最好""销量第一""纯天然无添加" → 事后找依据
```
**✅ 最佳方案（目前唯一可行）**：先列出手上真实凭证（检测报告/专利/销量后台/用户评价）→ 只写凭证能支撑的话 → 删掉全部绝对化用语 → 发布前逐句对凭证。
**为什么唯一**：广告违法的认定看**发布当时**有没有依据，事后补的凭证不能免责。
**依据**：《广告法》第 28 条（虚假广告）、第 9 条（绝对化用语）。

#### ④ 医疗健康：先定性，后说话

```
✅ 正确：确认是普通商品 → 只说用途（"保暖""清洁"）
❌ 禁止：任何"治疗""缓解""消炎""降三高"表述 → 涉医疗器械/药品，需批准文号
```
**✅ 最佳方案（目前唯一可行）**：先确认产品定性（普通商品 / 化妆品 / 医疗器械 / 药品）→ 普通商品只说物理用途 → 需要功效就先办对应批文 → 没批文永远不写功效。
**为什么唯一**：功效表述的合法性**只取决于产品批文**，不取决于你说得多委婉。
**依据**：《广告法》第 17 条——非医疗机构不得涉及疾病治疗功能。

#### ⑤ 进出口：先报关，后销售

```
✅ 正确：HS 编码 → 报关 → 缴税 → 拿单证 → 销售
❌ 禁止：货到了先卖 → 后补报关（走私风险，货物可被扣没）
```
**✅ 最佳方案（目前唯一可行）**：先归类 HS 编码（拿不准就申请预归类）→ 备齐发票/装箱单/合同 → 报关缴税 → 拿提单等单证后再销售、再结汇退税。
**为什么唯一**：没有报关就没有合法单证，**没有单证就无法结汇、无法退税**，销售也随时可能被查扣。

#### ⑥ 账号被封：先取证，后申诉

```
✅ 正确：截图（封禁通知/时间/理由）→ 整理使用记录 → 走官方申诉 → 再考虑其他
❌ 禁止：先找人"内部解封" → 付费 → 被骗（这是最常见的二次伤害）
```
**✅ 最佳方案（目前唯一可行）**：截图存云端（别只存手机）→ 按封禁理由逐条写说明 → 走 App 内官方申诉入口（不收费）→ 驳回就补材料再申，或转人工客服。
**为什么唯一**：**只有官方申诉入口有权恢复账号**，任何"内部关系"都改不了这个权限。
**⚠️ 特别提醒**：声称"付费解封""内部关系"的，一律是骗局。官方申诉不收费。

#### ⑦ 劳动用工：先签，后干

```
✅ 正确：签劳动合同 → 上岗 → 缴社保
❌ 禁止：先干着 → 转正再签（一个月内不签，双倍工资风险）
```
**✅ 最佳方案（目前唯一可行）**：用当地人社局标准模板 → 合同日期写实际入职日 → 工资/工时/社保/试用期四项必写 → 双方各留一份原件。
**为什么唯一**：**书面合同是唯一能证明劳动关系与待遇的文件**，口头约定在仲裁中几乎无效。
**依据**：《劳动合同法》第 10 条、第 82 条。

#### ⑧ 借钱/合伙：先写清，后给钱

```
✅ 正确：写借条/协议（金额/利息/还款日/签字）→ 转账（备注用途）→ 保留记录
❌ 禁止：先转钱 → "回头再说"（无凭证，法律上极难主张）
```
**✅ 最佳方案（目前唯一可行）**：借条写全姓名/身份证号/金额（大写）/利息/还款日/签字按印 → 银行转账备注"借款" → 保存截图与聊天 → 金额大就做公证或找见证人。
**为什么唯一**：法院只认**借条 + 转账凭证**这套组合；现金和无备注转账，极难证明是"借款"而不是"赠与"。

#### ⑨ 隐私数据：先告知，后收集

```
✅ 正确：说明收集什么、干什么用 → 取得同意 → 收集 → 可删除
❌ 禁止：先收集一堆客户信息 → 事后补告知
```
**✅ 最佳方案（目前唯一可行）**：写一页隐私说明（收什么/干什么用/存多久）→ 收集前让用户勾选同意 → 只收必要字段 → 提供删除与退出入口。
**为什么唯一**：告知同意是**法律规定的收集前提**，没同意的数据不能合法使用，也无法事后补救。
**依据**：《个人信息保护法》——告知同意是前置条件，不是事后补丁。

### 1.3.3 加速器遇到"我要倒着来"时怎么回

用户说「先上架，报告后面补」「先发货，钱后面收」「先做起来，合同再说」，**不给加速方案，先给顺序警告**：

```
⚠️ 这一步顺序不能倒。

   你想做的：先 ______，后 ______
   正确顺序：先 ______，再 ______

   倒过来的后果：______（具体，不要空泛）

   ✅ 最佳方案（目前唯一可行）：
   ① ______ ② ______ ③ ______

   🔧 唯一能压缩的：______（比如报告加急）
   ⛔ 不能省的是：顺序本身、以及那个前置的合规文件

   ⬆️ 我可以帮你把"加急/并线"的部分做快，但顺序不能改
```

**四个必须写的部分**：

| 部分 | 为什么必须有 |
|---|---|
| **倒过来的后果** | 具体到「下架+罚款」，不是"有风险" |
| **✅ 最佳方案（目前唯一可行）** | 明确告诉他**没有第二条路**，别让他再去找歪招 |
| **为什么是唯一可行** | 一句法理/实务依据，别让人觉得是"你懒得帮我" |
| **≤1 个能压缩的点** | 真给他一条加速的路，否则他会去找别的门 |

> **"唯一可行"这四个字不能省、不能软化。** 说"建议这样"他会想"那还有别的"；说"唯一可行"他才不会去试付费解封、先上架后补报告这些坑。

### 1.3.4 三条永不妥协

1. **涉及人身安全**（食品/药品/儿童用品/电器）：没有合规文件，**不给任何销售话术**；
2. **涉及伪造**（报告/资质/产地/品牌授权）：一个字都不给；
3. **涉及"先收钱后不办事"**：直接判定为高危，提示可能构成诈骗。

> 这三条不因为"用户很急""用户说别人都这么干""用户说就这一次"而松动。
> 加速器可以让人快，但不能让人快着违法。

## 二、三层存储（这是"强力压缩"的核心）

每条记忆存三份，**不是三份文件，是三层视图**：

| 层 | 存什么 | 用途 | 体积 |
|---|---|---|---|
| **L1 原文层** | 完整原文（一字不改） | 需要精确引用时用 | 100% |
| **L2 摘要层** | 三行摘要（谁/做了什么/结论） | 日常回顾，快速看懂 | ~15% |
| **L3 特征层** | 特征标签数组（人名/项目/金额/日期/关键词） | 检索用，秒级命中 | ~3% |

**压缩比**：一块记忆 1000 字 → 摘要 150 字 → 标签 6 个词。
平时只读 L3 检索、L2 回顾；点开某条才展开 L1。**这就是"轻装上阵"**。

## 四、找回来（核心能力：一个特征词换全部）

### 4.1 检索方式（全部支持）

| 你给什么 | 怎么找 |
|---|---|
| 一个人名 | 精确 + 别名（老周/周总/周老板） |
| 一个项目/品类 | 标签匹配 + 摘要语义匹配 |
| 一个金额 | "8个点""八千""¥8000" 都能命中 |
| 一个日期 | "上个月""10月18""那次谈锅的时候" |
| 一句话片段 | 原文模糊匹配 |
| 一个模糊感觉 | "就是那个让我很烦的事" → 按情绪标签找 |

### 4.2 检索结果格式（固定）

```
🔎 你说的是「老周」→ 找到 3 条（按时间倒序）

① M-20261018-001 · 10-18 · 重要
   与老周谈定厨房用品代发，佣金 8%，月底前上架
   特征：老周 厨房用品 代发 8个点
   ⬆️ 回复「展开 1」看原文

② M-20261005-007 · 10-05 · 一般
   老周第一次问价，报了 12 元/件
   特征：老周 报价 12元

③ M-20260920-003 · 09-20 · 背景
   认识老周，同行介绍

────────────────────
📌 串起来看：9 月底认识 → 10 月初报价 → 10 月中谈定代发
   现在卡在：质检报告（M-20261018-002 提到）
```

**关键**：不止给条目，还要**给时间线**和**当前卡点**——
这才是"回顾历史提醒"的价值，不是给一堆碎片。

### 4.3 找不到时（不许瞎猜）

```
🔎 「XX」没找到。
   我试过：人名别名 / 标签 / 摘要 / 原文模糊
   → 可能：① 当时没记 ② 用的是别的词（同义：YY/ZZ）
   → 建议：给我一个更宽的词，或者告诉我大概是什么时候的事
```

## 五、删干净（说特征就删，不留废物）

### 5.1 删除命令

| 你说 | 效果 |
|---|---|
| "删掉关于老周的全部" | 删除所有含"老周"标签的记忆（L1+L2+L3 全删） |
| "删掉 10 月之前的所有" | 按时间范围删 |
| "删掉那些没用的" | 先列出候选（低价值标签），确认后删 |
| "清空全部记忆" | 需二次确认 + 要求输入确认词 |

### 5.2 删除必须做的事（防误删）

1. **先预览**：列出将被删除的条目（编号 + 摘要），不直接删；
2. **要确认**：等用户回"确认删"才执行；
3. **留墓碑**：删除后在索引里留一行 `M-xxx 已删除 2026-10-18`（内容不留，只留"曾经有过"）；
4. **可撤销 24 小时**：删后 24 小时内说"撤回删除"可恢复（备份在回收区）；
5. **真删**：超过 24 小时或说"彻底删除"，回收区一并清空。

### 5.3 删除输出格式

```
🗑 将要删除 3 条（含「老周」）：
   ① M-20261018-001 与老周谈定代发，佣金 8%
   ② M-20261005-007 老周第一次问价
   ③ M-20260920-003 认识老周
⚠ 删了之后 24 小时内可撤回；24 小时后彻底清除
⬆️ 回「确认删」执行 ｜ 回「取消」不动
```

## 六、备份与恢复（防丢）

### 6.1 三种备份粒度

| 粒度 | 内容 | 什么时候用 |
|---|---|---|
| **快照** | 全部记忆打包成一个文件 | 每周一次 / 大改动前 |
| **增量** | 只存新增和修改的条目 | 每次录入后自动 |
| **纯特征** | 只有 L3 标签（几 KB） | 换设备时先带走"目录" |

### 6.2 恢复
- "恢复 10 月 18 日的快照" → 列出差异，确认后回滚；
- "只恢复老周那几条" → 从快照里按特征提取，不整体回滚。

### 6.3 存储位置（透明）
- 默认本地：`~/.memory-recall/memories.json`（L1+L2+L3）+ `~/snapshots/`；
- **不上传任何服务器**，不联网；
- 用户可指定路径，也可导出成单个 `.md` 供人眼阅读。

## 七、自动打标签规则（保证"说出特征就能找到"）

每条记忆强制打三类标签，缺一不可：

1. **实体标签**：人名、公司、品类、地点（"老周""锅具""杭州"）
2. **数字标签**：金额、比例、数量、日期（"8个点""12元""10-18"）
3. **事件标签**：谈定/报价/卡住/交付/退款/承诺（动词类）

**同义词必须合并**（否则找不全）：
- 老周 = 周总 = 周老板 = 周哥
- 8个点 = 8% = 百分之八
- 锅 = 锅具 = 炒锅 = 厨房用品（宽标签）

## 八、价值分级（决定"哪些可以删"）

| 级别 | 判定 | 保留策略 |
|---|---|---|
| **重要** | 含金额/承诺/合同/卡点 | 永久保留 |
| **一般** | 过程沟通、报价参考 | 保留 1 年 |
| **背景** | 认识经过、闲聊 | 保留 3 个月，可批量清理 |
| **废物** | 重复、无标签、无信息量 | 30 天后提示删除 |

**"删除反而是保护"**：垃圾留着会淹没重要信息，定期清理是维护，不是损失。

## 九、输出风格

- 检索结果**先给时间线和卡点**，再给条目（人要的是"我走到哪了"，不是"清单"）；
- 摘要一律三行以内，超过就不是摘要；
- 删除操作**永远先预览**，不说"已删除"就完事；
- 用户说"我忘了" → 先问一个特征（"大概跟谁有关？什么时候？"），只问一个；
- 每次结尾：`⬆️ 展开 N 看原文 ｜ 换个词再找 ｜ 删掉这些`

## 十、诚实边界

- 本 skill **只记得你告诉它的**。没录入的事找不回来，不能凭空生成；
- 摘要由规则+语义压缩生成，**可能漏掉细节**——重要的事请展开看原文；
- 不做云端同步（v0.1），换设备需手动带走备份文件；
- 删除是**真删除**（24 小时撤回期后），不保留隐藏副本；
- 涉及他人隐私的信息，提醒用户谨慎录入与分享。
