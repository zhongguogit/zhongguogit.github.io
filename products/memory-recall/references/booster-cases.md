# 加速器案例库（60 条照念稿）

> 用法：卡在哪，就找哪一组，**照着念第一句**。念完对方有反应了，再念第二句。
> 每条都满足：一口气念得完（≤25 字）、不用懂也能念、念完对方必须接话。

---

## 使用说明（先看这一屏）

### 照念稿的三条铁律

1. **只改数字，不改句式**——改了句式就变成"现场组织语言"，又卡住了；
2. **念完就停**——不要急着补解释，等对方回应；
3. **对方压价就退到下一句**，别硬顶。

### 案例来源标记

| 标记 | 含义 | 可信度 |
|---|---|---|
| 🟢 **你自己的** | 来自你记录过的历史（带 M- 编号） | 最高，直接用 |
| 🟡 **通用句式** | 没人做过，按常规写法给的 | 中等，要按自己情况改 |

> 🟡 必须标出来。**不能把通用句式说成"你以前这么干过"**——那是伪造记忆。

## 九、怎么把 🟡 变成 🟢（越用越快）

```
今天用第 2 条（🟡 通用）谈了价
     ↓ 谈完
你说「搞定了，最后到 6 个点，条件是月销 3000」
     ↓
skill 存成 M-xxx，打标签：报价 / 案例 / 6%
     ↓ 下次遇到同类
弹出来的就是 🟢：「月销3000件的话，能不能到6个点？」（而且带日期）
```

**第一批 60 条全是 🟡。** 用满一个月，最常用的那 10 条会变成 🟢——那时候给你的就全是你自己的原话。

## 十、绝对不给的照念稿

以下需求**不提供话术**，直接说明原因：

| 需求 | 为什么不给 |
|---|---|
| "怎么说才能让他以为是进口的" | 虚假产地，违法 |
| "怎么说能让他先付款再发货，其实我没货" | 诈骗 |
| "怎么绕过平台私下交易" | 违反平台规则，且买家无保障 |
| "怎么说能让他相信这个能治病" | 虚假宣传，涉药涉医更高风险 |
| "怎么把不合格报告说成合格的" | 伪造文书 |
| "怎么让他不敢投诉" | 威胁 |

**统一回复**：
```
这条我不能给你话术。
原因：______（一句话说清是哪类问题）
能给的替代：______（比如"如实说明情况，用样品和检测报告建立信任"）
```

> 加速器的价值是"让你敢开口"，不是"让你能骗人"。给一次违规话术，这个 skill 就废了。
