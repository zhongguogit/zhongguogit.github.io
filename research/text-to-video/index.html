Local Deployment

本地部署速查

三条最常用的开源路线，命令可直接复制。显存不足时优先考虑量化或 CPU offload。

Wan2.2-TI2V-5B

Apache 2.0 · 约 24GB 显存 · 商用最省心
# 拉权重
hf download Wan-AI/Wan2.2-TI2V-5B \
  --local-dir ./Wan2.2-TI2V-5B

# 生成
python generate.py \
  --task ti2v-5B \
  --size 1280*704 \
  --ckpt_dir ./Wan2.2-TI2V-5B \
  --prompt "your prompt"

HunyuanVideo 1.5

社区许可 · 8.3B · 最低 14GB（offload）
# 拉权重
hf download tencent/HunyuanVideo-1.5 \
  --local-dir ./HunyuanVideo-1.5

# 开启 offload 降低显存
python sample_video.py \
  --model-path ./HunyuanVideo-1.5 \
  --prompt "your prompt" \
  --enable-offload

LTX-2.5（含音频）

LTX 社区许可 · 22B 蒸馏 · 最高 4K/50fps
# 蒸馏版推理
uv run python -m ltx_pipelines.distilled \
  --prompt "your prompt" \
  --height 1024 --width 1536 \
  --num-frames 121 \
  --frame-rate 24
许可 Tencent Hunyuan 社区许可不含 EU / UK / 韩国；LTX 与 Stability 均为社区许可，商用前务必逐条核对。
