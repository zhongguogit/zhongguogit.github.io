# 审改已有 Skill · 逐项检查表

> 用法：读一遍目标 SKILL.md，按下表逐项过。每项给出 **PASS / WARN / FAIL + 行号 + 改后文本**。
> 自动化部分交给 `scripts/validate_skill.py`，本表覆盖脚本查不出但需要人判断的部分。

## A. 触发层（决定它会不会被用上）

| # | 检查项 | 不通过信号 |
|---|---|---|
| A1 | `description` 写了**触发条件**（用户会怎么说）而非能力介绍 | 「XX 连接器 - 用于…」「提供 XX 能力」 |
| A2 | 含用户真实口吻的短语/别名/拼写变体，中英双语 | 只有书面术语 |
| A3 | 有 `NOT for <近邻任务>` 排他段 | 完全没有排他条件 |
| A4 | 排他条件尽量**机器可判定**（如一句 grep） | 「如有更合适的工具则不要使用」 |
| A5 | 有副作用且不可逆 → 考虑 `disable-model-invocation: true` | 部署/删除/推送类 skill 允许模型自动调用 |

## B. 结构层

| # | 检查项 | 不通过信号 |
|---|---|---|
| B1 | 安全/闸门段在**第一屏**（命令之前） | 安全警告排在「注意事项」末尾 |
| B2 | 正文 ≤500 行 | >500 行 |
| B3 | `references/` 引用**只深一层**，无嵌套链 | `a.md` → `b/c.md` → … |
| B4 | >300 行的 reference 有目录 | 无目录 |
| B5 | 每个 `scripts/` 入口都在正文被点名且说明**何时用** | 孤儿脚本（本机 gongfeng/figma 即是） |
| B6 | 正文引用的每个文件都真实存在 | 引用不存在路径 |
| B7 | 术语全文一致（同一个东西不换称呼） | CLI/命令行/工具混用 |

## C. 执行层（工具类特有）

| # | 检查项 | 不通过信号 |
|---|---|---|
| C1 | 有强制 **Preflight**：命令存在 → 版本 → 认证 → 连通 → scope | 只有「需要先获取 token」这类提示 |
| C2 | Preflight 是**脚本**不是祈使句 | 「请先确认已安装」 |
| C3 | 有退出码契约 + 失败分支（停 → 重跑一次 → 仍失败则停止） | 无 |
| C4 | 命令模板「只允许填空、不允许改结构」 | 每次命令格式都不同 |
| C5 | 不确定 flag 时要求先 `--help` 原样复制 | 允许凭记忆构造 |
| C6 | 有输出裁剪约定（--limit / jq / head，且保留尾部） | 允许裸 `list` / `cat` |
| C7 | 重试与熔断**在脚本层计数** | 「最多重试 3 次」只写在文档里 |
| C8 | 有 L0/L1/L2/L3 副作用分级与确认门 | 合并/删除/force push 直接执行 |
| C9 | 降级顺序显式化，且切换前确认无副作用 | 静默降级 |
| C10 | 称「已完成」前要求**回读验证** | 无 |

## D. 凭据层

| # | 检查项 | 不通过信号 |
|---|---|---|
| D1 | SKILL.md / scripts / examples 内**零真实凭据** | 出现疑似 key |
| D2 | 示例用 `<YOUR_TOKEN>` 占位 | 示例里是可用的假 key |
| D3 | 禁止 `env` / `printenv` / `set -x` / `curl -v` / `--show-token` | 诊断命令即泄露通道 |
| D4 | 验证认证只用布尔命令，只回传 OK/FAIL | 回传身份详情 |
| D5 | 禁止把 token 写进 git remote URL / shell rc / 日志 | 本机 get_token.sh 即违反 |

## E. 跨宿主可移植

| # | 检查项 | 不通过信号 |
|---|---|---|
| E1 | frontmatter 顶层键只有 6 个（version/author 塞 `metadata`） | 顶层出现第 7 个键 |
| E2 | 无时间敏感句（「2025 年 8 月后请用新 API」） | 有 |
| E3 | 依赖与网络需求写在 `compatibility` | 假设依赖已装 |
| E4 | 只用相对路径 + 正斜杠 | 硬编码绝对路径 |

## 输出格式

审完给出三张表：**必须改**（FAIL）、**建议改**（WARN）、**已通过**。每条 FAIL 附**可直接粘贴的改后文本**，不要只给方向。
