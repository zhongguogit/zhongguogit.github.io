# 脚本契约规范

> 工具/集成类 skill 的核心原则：**能用代码确定的，不要用祈使句兜底**。
> Anthropic 官方口径：「关键校验优先用脚本，代码确定，语言解释不确定」。

## 一、什么逻辑该下沉脚本

| 下沉（脚本） | 留在 SKILL.md（模型判断） |
|---|---|
| 依赖是否安装、版本是否匹配 | 用户意图识别 |
| 认证布尔检查、连通性探测 | 参数取值（依赖上下文） |
| 重试、退避、熔断计数 | 结果解释与用户沟通 |
| 错误码 → 动作的映射 | 何时加载哪个 reference |
| 输出裁剪、结构化 | 是否触发 L2 确认门 |
| 幂等键生成与存在性检查 | |

判据借用官方 degrees of freedom：**易碎、要求一致的部分脚本化；随上下文变化的部分留给模型。**

## 二、stdout 是唯一契约

脚本与模型之间只通过 stdout 通信。禁止让模型读脚本源码来推断行为——官方 `webapp-testing` 范式明确要求「先 `--help`，不要读源码」。

**成功**：输出一行结构化数据，退出码 0。

```json
{"ok": true, "id": "...", "status": "created"}
```

**失败**：输出一行错误 JSON，退出码**非 0**。

```json
{"ok": false, "error": "SERVICE_UNREACHABLE", "detail": "...", "retryable": false}
```

规则：
- 错误对象必须含**机器可匹配的错误码**，不能只有人类可读文本。否则模型只能靠语义猜（本机 `automation-task-manager` 的错误码表与脚本实际输出对不上，就是死契约）。
- 退出码非 0 一律视为失败，**即使输出看起来正常**。
- 需要给证据时给日志尾部（末 15 行非空），而不是给结论。

## 三、Solve, don't punt

脚本自己兜住可预见的错误，不要抛回给模型：

```python
try:
    config = json.loads(path.read_text())
except FileNotFoundError:
    config = DEFAULT_CONFIG   # 自己兜，不要抛
    path.write_text(json.dumps(config, indent=2))
```

所有常量自证一行为什么：

```python
MAX_RETRIES = 3      # 三次重试平衡可靠性与速度；再多是无效重试
TIMEOUT_SEC = 60     # 对齐大多数 CI 的单步超时预算
```

禁止 voodoo constants（裸数字无解释）。

## 四、幂等契约

写操作要么带幂等键，要么显式禁止重试：

- 优先用服务端 idempotency key；
- 服务端不支持 → **不重试**，报「结果未知」交人判断；
- 写操作超时 ≠ 失败。**先按业务键做存在性检查，查不到再重试，且复用同一 key**（重新生成 key 等于放弃幂等）。
- 重试/熔断计数在脚本层实现，**不靠模型的上下文记忆**（长任务里必然失效）。

## 五、错误分类表（必须写进脚本分支）

| 类别 | 例子 | 动作 |
|---|---|---|
| 可重试 | 超时、429、5xx、连接重置 | 退避重试，最多 2 次 |
| 终态-认证 | 401 + `invalid_grant`/`invalid_token` | 不重试，提示重新认证 |
| 终态-权限 | 403 | 不重试，说明缺什么 scope |
| 终态-参数 | 400、404、422 | 不重试，原样回传错误里的 field 名 |
| **伪装成功** | **HTTP 200 但 body 含 `error` / `ok:false`** | **单独分支，视为失败** |

最后一条是 `claude-api` 官方 skill 明确点出的坑：200 不等于成功。

## 六、调用姿势统一

- 定位统一用 `<skill-directory>`（SKILL.md 里定义一次：「本 Skill 所在目录，非用户项目目录」）或宿主注入的 `${SKILL_DIR}`；
- 脚本内部用 `require('./lib')` / `Path(__file__).parent` 相对**自身**定位，不依赖 cwd；
- 路径只用正斜杠，禁 Windows 路径与任何 skill 之外的绝对路径；
- 传参数用 `--arg` / `--data @file.json` 结构化传值，**绝不把用户字符串拼进命令行**。
