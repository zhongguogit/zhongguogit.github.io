# 那个报错，折磨了他四天

> 系统化排障 root-first · ¥39

代码跑不起来，报错信息像天书。

程序员小唐盯着这个bug已经四天了。改了这里，那里炸；修好那里，这里又炸。他凌晨两点在搜索框里输入"玄学报错怎么办"，认真考虑过转行。

第二天他买了个叫 root-first 的排障技能包，三十九块。买它的原因很肤浅——介绍里说"先修根因，再碰代码"。

包里的第一步就打了他一记闷棍：别急着改代码。先把"怎么让这个错误稳定复现"写出来。他愣了一下——四天来他一直在"试着改改看"，从没想过要先让错误听指挥地出现。

第二步是缩小：把复现步骤一层层砍，砍到最小。包里还配了个小脚本，自动帮他二分定位。半小时后，他把四天的"玄学"砍成了三行代码的场景：并发时两个请求同时改同一份数据。

根因找到了。修复用了十五分钟。

四天的坑，真正的洞只有一个，他之前一直在填坑边上刨土。

现在他的电脑桌面贴着一张便签，是包里那张核对清单的第一行：**先复现，再缩小，最后才动手。**

他说这三十几块买的不是工具，是一副眼镜。以前满世界都是雾，现在他知道雾里哪一块是有东西的。
