# 按我说的来

手机 App 风格的剧情网页应用（单文件 HTML，零依赖）。

## 故事
一个什么都不会、也不知道自己该干什么的傻子（实为 007 专业执行者），开着空天航母停在体育馆正中央。
看台墙上人才辈出（环形肖像名人墙），航母正中悬浮 7 个框：发起人 + 6 位专家。
发起人一声「起飞！」→ 航母点火 → 6 位专家实时指挥他去赚钱 →
第一晚没赚到钱 → 点看台上发亮的高人换人上场 → 最终「傻子无所不能了」。

## 玩法
1. 点「让 6 位专家帮我赚钱」看实时指挥
2. 照做 → 结算第一晚：只赚 ¥8（没赚到钱）
3. 点看台上发亮的「高人」换人上场
4. 自动进入最终结局：傻子无所不能了

## 测试状态
顶部横幅显示当前为「测试版 BETA TESTING」，每跑完一轮完整剧情，测试进度 +1（共 5 轮），
进度达 100% 后横幅变为绿色「测试通过 · 可上线运营」。
